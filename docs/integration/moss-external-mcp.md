# NV9 第三方 MCP 使用与契约

## 使用位置

MOSS 桌面端 → 语音中心 → 第三方 MCP。支持 **stdio 本机程序**与 **Streamable HTTP**，不支持独立旧版 SSE 或自动 OAuth 登录。

添加服务后默认停用。填写地址，或填写程序及 JSON 参数数组；密钥放在请求头／环境变量凭据栏，不要放进地址、参数或普通说明。勾选启用并确认后才开始连接。已启用的服务随后会随桌面程序启动；只有内置语音会话能使用这些工具，官方／自建小智接入点不会获得这些外部工具。

每个工具有三档权限：禁用、每次需批准（默认）、免批准。免批准只适合用户已核实的可信只读工具；第三方的 `readOnlyHint` 声明不会自动放行。stdio 不是沙箱：你配置的程序仍拥有当前系统用户权限，批准工具调用不等于限制程序启动时的行为。

## 桌面命令与窗口边界

只有主窗口 `main`、当前实际后端的精确回环来源、有效桌面会话三项同时满足时才可调用。专用 capability 为 `voice-mcp`，不向任意窗口或远程页面授予这些命令。Android 只编译拒绝调用的命令占位，不启动外部 MCP。

| Tauri 命令 | 参数 | 行为 |
| --- | --- | --- |
| `voice_mcp_status` | 无 | 配置、凭据是否存在、连接、工具、内存计数与最近审计；不返回凭据值 |
| `voice_mcp_save` | `input: {expected_revision, config, secrets, confirmed, allow_without_approval}` | 按配置版本校验后保存；必须确认，存在免批准工具时还须确认其风险 |
| `voice_mcp_delete` | `name, revision, confirmed` | 停止连接、使未执行审批失效，删除配置和当前引用凭据 |
| `voice_mcp_reconnect` | `name, confirmed` | 重建连接，不补发旧工具调用；stdio 程序可能重新启动 |

命令失败返回 `{code:"voice_mcp_error", message}`。旧表单版本冲突时拒绝覆盖，刷新后重新编辑。没有对应的 HTTP 管理路由，也没有让语音添加程序或密钥的工具。

## 配置与凭据

`settings.json` 的 `voice.mcp_servers` 为数组，每项：

```json
{
  "name": "notes",
  "enabled": false,
  "transport": {
    "type": "streamable_http",
    "url": "https://example.test/mcp",
    "header_refs": {"authorization": "voice.mcp.notes.header.authorization"}
  },
  "policies": {"read": "ask"}
}
```

stdio 的 transport 使用 `{type:"stdio", command, args:[], env_refs:{}}`。服务名最长 32 位，采用英文、数字、单下划线或横线，不能含 `__`，保留 `device` 名称。工具别名为 `服务名__原工具名`，最长 64 字符，不静默截名。最多 8 个服务。HTTP 凭据只允许 HTTPS 或本机回环，不跟随重定向；URL 不允许用户名、密码、查询或片段。协议请求头不能被用户自定义字段覆盖。

凭据保存在现有 SQLite `app_secrets`，没有新增加密方案；数据库备份仍需妥善保管。保存时生成带 `.v-<32位标识>` 的新引用，先提交凭据和审计，再原子更新配置文件；故障时不会让旧配置错误地读到新密钥。普通语音／模型设置的旧表单不能覆盖专用 MCP 配置。

凭据输入框留空只保留当前服务同字段已保存的值；移除字段后保存才删除该项当前引用。成功保存后清理被替换的旧引用。崩溃或配置文件写入失败时可能留下不可达的版本凭据，本期不做广泛扫描清理；旧配置及其旧凭据保持可用，受影响的运行连接保持暂停，用户检查后再重新连接。状态、审计和错误不回显凭据值。

## 连接、数量与统计

独立连接任务使用专用运行时，不借用语音收发循环。正常空闲时每 30 秒心跳并刷新工具清单，调用超时 30 秒；出错后按 1、2、4、8、16、32、60 秒退避重连，健康心跳后归零。同一服务调用串行、有界队列 16 项；不同服务独立。

每个服务最多发现 256 个工具、8 页；过大清单拒绝接入。桌面可以查看受限工具并禁用不需要的项；**所有外部工具合计最多 64 个进入模型**。同名或超预算工具不仅隐藏，调用入口也拒绝。单工具描述最多 200 字符，参数对象最多 32 KiB，工具返回值最多 512 KiB；模型文本结果另限 1500 字符。这些是应用层边界，不代表第三方程序或其 SDK 内部没有其他内存分配。

工具调用次数、失败数、最近时间为本次运行内存统计；连接重建保留已观察到的计数。审批与审计持久保存。页面显示连接状态、退避时间、名称冲突／数量限制原因和最近 50 条相关审计（从最近 200 条全局审计中筛选）。

## 持久审批与审计

语音身份绑定已允许的 device/session。默认 Ask 不调用下游，只创建 `external_tool` 审批并朗读“已发到电脑，本次尚未执行”；批准后的结果在桌面审批中查看，本期不主动回推语音播报。

审批沿用桌面 `/v1/approvals` 流程，显示工具、来源设备和有界参数预览。确认文案是“核对第三方工具、参数及数据访问范围”，不是激光机器现场确认。参数预览可能截断，疑似密钥字段隐藏；执行使用隐藏的完整请求，而不是预览文字。

摘要绑定服务／目标、凭据版本、工具 schema、权限、完整参数和来源会话。模型填写 `confirmed` 或 `approval_id` 不构成授权。批准、实际调度前都复核，授权单次消费；修改配置／凭据／策略或撤销设备会作废未消费审批。每台设备最多 16 条待处理请求，合计上限 256；编号由宿主产生，不复用模型自报编号。

`ApprovalKind` 新增 `external_tool`；审计新增 `external_mcp_config_changed`、`external_tool_requested`、`external_tool_completed`、`external_tool_denied`。不记录完整参数、结果、地址和凭据到审计。完整调用参数仅保存在本机审批隐藏 request 中；数据库本身可能包含用户数据。执行前审计失败即拒绝；执行后结果或审计写入失败则明确提示“操作可能已执行，不要重复操作”。

发生 401、404、断线或超时均**不自动重放 `tools/call`**，结果未知时不能说执行成功或安全重试。进程在审批已消费但结果未记入期间退出，下次恢复为结果未知，不恢复执行。已交给第三方的操作不保证可以撤回；停止连接只能阻止后续调用。

本次未修改数据库表结构，schema 仍为 6，但新增枚举值属于向旧应用不兼容的数据扩展。需要回退旧程序时应使用升级前数据库备份，不让旧程序继续读取已写入新审批／审计类型的库。

## 验证与边界

自动验证包括 Node 假 stdio 子进程、本机回环 HTTP 假服务、临时 SQLite／设置文件、浏览器假 Tauri 桥。覆盖默认审批、重复批准、撤销／过期、配置及 schema 改变、审计失败、结果未知不重放、心跳重连、预算、密码不回显、旧表单覆盖防护，以及 1280/960 像素页面操作。

执行命令：`cargo test --workspace --no-fail-fast`；`cd frontend; npm test`；`cd frontend; node tests/voiceMcp.browser.mjs`（需要 Playwright，Windows 默认使用独立无头 Edge）；回环 E2E 和三端构建遵循 AGENTS.md。

真实第三方服务器、真实账号、复杂服务兼容性和实机语音仍为未验证，实际运行结果记录在 CHANGELOG 和实施 TODO。此功能不替代激光安全门禁，也不替代本地语音辅助程序的安装包集成。
