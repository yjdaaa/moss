# 快速开始

面向在 Windows 上使用 MOSS 控制翼宿 V1.0 / FluidNC 激光机的用户。开发、测试与构建规范见 [开发规范](../developer/standards.md)。

## 1. 准备

- Windows 10/11。自行编译时需要 Rust 1.98+（stable，MSVC 工具链）和 Node.js 20+；只运行已编译的 `.exe` 时不需要。
- 激光机通过 USB 串口或局域网连接。网络模式只走 Telnet（默认端口 23），FluidNC 侧需要开启的项见 [FluidNC 固件侧配置](../laser/fluidnc-setup.md)。
- 想用小智语音控制时，准备小智控制台生成的 MCP 接入点地址。

## 2. 启动

### 方式 A：双击 `scripts/start.bat`

- 默认以桌面模式启动 `target/release/moss-desktop.exe`（没有 release 时退回 `target/debug/`）。
- `start.bat -Server` 或 `-Host`：改为启动 `moss-host.exe serve`，并用浏览器打开页面。
- 两个可执行文件都不存在时，脚本会执行 `cargo build --release -p moss-desktop -p moss-host`。这条命令依赖仓库根目录的 Cargo workspace 清单。

### 方式 B：命令行

```powershell
# 桌面端（Tauri 2，进程内自带后端）
cd apps/desktop/src-tauri
cargo tauri dev

# 无界面宿主（HTTP + MCP 桥），控制台会打印实际监听地址
cd apps/moss-host
cargo run -- serve

# Android 调试包
cd apps/desktop/src-tauri
cargo tauri android build --debug --target aarch64 --apk
```

`moss-host serve` 启动后打印 `moss-host serving on <host>:<port>`，以及 MCP 桥是否启用。

### 端口

- 代码默认端口是 `9666`。可用环境变量 `LASER_WEB_PORT` 覆盖，或在界面"偏好设置 → 服务监听端口"修改；界面修改写入运行目录的 `settings.json`，下次启动生效。端口被占用时服务会回退到可用端口；桌面及 Android 内嵌页会获取本次实际端口，若后端启动失败则显示错误，不会误连到占用 9666 的服务。独立 Vite 开发页仍以 9666 为默认目标。
- 首选端口被占用时，宿主会自动向后尝试 50 个端口，再不行就由系统随机分配。实际端口以控制台输出为准。
- `start.bat -Server` 会等待宿主输出实际监听地址后再打开浏览器；首选端口被占用并自动回退时，也会打开回退后的端口。

## 3. 配置文件 `.env`

`.env` 所有项都可选，程序按以下顺序查找，先找到的值优先、后面的不会覆盖：

1. 系统或用户环境变量；
2. 启动时当前目录（及上级目录）里的 `.env`——开发时通常是仓库根目录；
3. 数据目录里的 `.env`，Windows 上是 `%APPDATA%\moss\.env`。

安装版从开始菜单或桌面快捷方式启动时当前目录不确定，第 2 项可能找不到；这时把 `.env` 放到 `%APPDATA%\moss\.env` 即可，和装在哪个目录无关。端口和小智地址也可以直接在界面设置里改（写入 `%APPDATA%\moss\settings.json`；小智地址以界面设置为准，端口以环境变量 / `.env` 为准）。真实 token、设备 IP、串口号只放本机 `.env`，不要写进文档或提交。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MCP_ENDPOINT` | 未设置 | 小智控制台的接入点，形如 `wss://<host>/mcp/?token=<token>`。桌面端也可在“系统偏好设置 → 小智 MCP 网关端点”中输入并保存；运行目录 `settings.json` 优先于环境变量，保存后重启生效 |
| `LASER_WEB_HOST` | `127.0.0.1` | HTTP 监听地址。绑定 `0.0.0.0` 后局域网设备可访问，但需要配对（见第 7 节） |
| `LASER_WEB_PORT` | `9666` | HTTP 监听端口 |
| `LASER_DEFAULT_CONNECTION_MODE` | `network` | 默认连接方式，`network` 或 `serial` |
| `LASER_ENGRAVING_MODE` | `raster` | 默认雕刻策略，`raster` 或 `outline` |
| `LASER_MATERIAL_PARAMS_FILE` | 未设置 | 材料库 JSON 文件路径。未设置时使用内置材料库，保存的参数只写入 SQLite |
| `GRBL_DEFAULT_PORT` | 未设置 | 串口模式的默认串口，例如 `COM3`。未设置时必须在界面选择 |
| `GRBL_BAUDRATE` | `115200` | 串口波特率 |
| `LASER_NETWORK_HOST` | 未设置 | 网络模式的默认设备地址。未设置时必须在界面填写或扫描 |
| `LASER_NETWORK_TELNET_PORT` | `23` | Telnet 端口 |
| `MOSS_ENABLE_DEVELOPER_COMMANDS` | 未设置 | 设为 `true` 才向小智开放 `command_execution_tool`，仅供本机调试 |
| `MOSS_ALLOWED_ORIGINS` | 未设置 | 额外允许跨源访问的浏览器页面来源，逗号分隔，如 `http://<主机>:<端口>`。桌面端、MOSS 自带页面和前端开发端口已默认允许，一般不用设置。不允许写 `*`，写了会启动失败 |

## 4. 运行目录

运行数据不写入源码目录，也不写入程序目录。运行目录按以下顺序确定：显式指定 → 可执行文件同级的 `.runtime/` → `%APPDATA%\moss` → 当前目录的 `.runtime/`。桌面端与 `moss-host` 启动时既不传显式路径也不传可执行文件路径，因此 **Windows 上实际使用 `%APPDATA%\moss`**（没有 `APPDATA` 环境变量的系统才退回当前目录的 `.runtime/`）。安装到任何目录都不影响数据位置，卸载程序默认也不会删除这里的数据（见 [安装包与卸载规范](../developer/packaging-install.md)）。

目录内包含 `uploads/`、`previews/`、`generated_assets/`、数据库 `moss.sqlite`、界面设置 `settings.json` 和实例锁 `moss.lock`。同一运行目录同时只允许一个实例，第二个实例会因为拿不到锁而初始化失败。

从旧 Python 版迁移数据：

```powershell
cd apps/moss-host
cargo run -- migrate --from <旧项目根目录> [--target <运行目录>] [--dry-run] [--on-conflict keep|overwrite]
# 不写 --target 时迁到程序实际使用的数据目录（Windows 为 %APPDATA%\moss）
```

迁移报告写入运行目录的 `migration-<时间戳>.json`；旧的未完成任务一律标为失败，不会自动续跑。

## 5. 界面

| 路径 | 用途 |
| --- | --- |
| `/` 主页 | 选择串口或网络连接（串口列表只显示系统真实识别到的串口；网络可点"扫描局域网"用 mDNS 发现 FluidNC）、文字雕刻任务、发送进度条、`0x18` 软件复位按钮、通信终端与小智桥接状态抽屉 |
| `/draw` 画板 | Excalidraw 手绘或导入图片，生成预览，"走边框"校位，确认发送；可勾选 SD 卡脱机模式 |
| `/material-lab` 材料实验室 | 材料库增删改、导入导出，生成并发送测试矩阵，选出最佳格写回材料库 |
| `/voice` 语音中心（仅桌面端） | 小智链路（官方 / 自建）、自建服务端启停与日志、模型配置、审批记录，见第 8 节 |

桌面端关闭窗口时会询问"最小化到托盘"或"退出"，可记住选择。退出、崩溃或关闭控制台都会先向在途作业写入 `0x18` 再退出。如果语音中心里由 MOSS 启动的语音服务端还在运行，退出时会再问一次是否一并停止（默认停止）；MOSS 崩溃时它会随之结束，不会留在后台。

## 6. 第一次雕刻

1. 生成预览。预览只解算 G-code 并冻结文件 SHA-256 与加工参数，不连接机器。
2. 核对机器上实际放置的材料与厚度和预览一致。系统不会自动识别真实材料。
3. 在画板点"走边框"。这一步会真实驱动机器沿图形外接矩形运动，用来校对摆放位置。默认不出光、只移动激光头；需要在材料上看到边框时勾选"走边框时弱光指示"（约 0.1% 功率）。走边框期间顶栏急停可以停止它。
4. 确认发送。发送前会重新计算文件 SHA-256、与机器握手（要求 `$32=1`、读取 `$30` 功率标尺）、确认机器处于 Idle 且无急停/故障/门开信号；设备预检后再读取文件与已确认哈希比对，后续只发送这一份已验证的内容。任一项不通过都不会写入加工指令。
5. 进度 100% 只表示所有行已被机器接收。系统随后发送 `G4 P0` 同步并等待 Idle，状态变为 `completed` 才算完成。
6. 中途要停：主页的红色 `0x18` 按钮是软件复位请求，不是物理急停。机器上的硬件急停按钮仍然必须可及。

SD 卡脱机模式：确认发送后文件先经 FluidNC 的 HTTP 上传到 SD 卡，比对固件计算的哈希后执行 `$SD/Run`，进度来自固件状态报告。固件未启用 HashFS、拿不到文件哈希时不会执行，请在固件中启用 HashFS 或改用逐行发送。脱机作业进行中，机器只接受急停、暂停、继续等实时字节。

## 7. 手机或局域网访问

### 7.1 手机 App 连接电脑 MOSS（推荐）

电脑是唯一的数据源：手机使用电脑上的材料库与任务记录，经电脑操作雕刻机（连接、预览、发送、走边框、急停）。手机上材料、校准参数和系统设置**只读**，只能在电脑上修改（后端强制，局域网浏览器访问同样适用）。需要电脑开着 MOSS，手机与电脑在同一个 WiFi。

1. 电脑：偏好设置 → **手机连接** → 勾选“允许手机连接”，完全退出并重新打开 MOSS。首次启动 Windows 防火墙若弹窗，勾选“专用网络”并允许。
2. 电脑：同一分区会显示手机要填写的地址（如 `192.168.1.20:9666`），点“生成配对码”得到 6 位数字（5 分钟内有效）。
3. 手机 App：偏好设置 → **连接电脑 MOSS** → 填地址 → 连接。App 重新加载后会弹出配对窗口，输入配对码。
4. 电脑重启后配对失效，手机会再次弹出配对窗口，在电脑上重新生成配对码即可。
5. 手机偏好设置中“断开，改用手机本机模式”可回到手机内置的独立 MOSS（数据与电脑不互通）。连不上电脑时启动页也提供“改用手机本机模式”。

### 7.2 其他设备用浏览器访问

开启“允许手机连接”（或把 `LASER_WEB_HOST` 设为 `0.0.0.0`）并重启后，同一局域网的设备可以用浏览器打开 `http://电脑IP:端口`。非本机访问的数据接口需要一次性配对：配对码在电脑 MOSS 偏好设置“手机连接”中生成，或在电脑本机执行：

```powershell
curl -X POST http://127.0.0.1:9666/v1/auth/challenge
```

在页面弹出的配对窗口输入配对码。token 只保存在电脑 MOSS 进程内存中，电脑重启后需要重新配对；连续输错会被临时锁定。浏览器访问与手机 App 一样，材料与设置只读。

不要把服务暴露到公网。跨网访问必须由前置代理终结 TLS。

## 8. 小智语音

桌面端在左侧“语音中心”填写小智接入点（见下文“语音中心”）；独立 `moss-host` 与手机端仍在偏好设置中填写，或在 `.env` 写入 `MCP_ENDPOINT`。配置后，桌面端和 `moss-host serve` 启动时会自动连接小智，断线按 1 秒到 60 秒指数退避重连（每 30 秒发一次心跳，90 秒收不到任何数据也会判定断线重连），日志中的 token 会脱敏。主页顶栏的"小智"胶囊与控制台抽屉的"小智 MCP 桥接状态"页显示连接状态和最近请求。

小智控制台的提示词与知识库文本以 [integration/xiaozhi-prompts/latest.md](../integration/xiaozhi-prompts/latest.md) 为准。语音只能触发预览、状态查询、受控安全动作和已确认的发送，底层门禁与网页相同。

### 严格模式：语音加工需要在电脑上批准（可选，默认关闭）

在运行目录的 `.env`（Windows 安装版为 `%APPDATA%\moss\.env`）加入一行 `MOSS_FUSION_STRICT=true`，完全退出 MOSS 后重新打开即生效：

- 小智或局域网设备要求开始加工、走边框、回原点、移动等动作时，不会直接执行；MOSS 桌面端会在任何页面弹出审批卡，并在顶栏“审批”按钮上显示数量。
- 核对卡片上的预览、材料、功率、速度和目标设备，勾选“我在机器旁，材料已放好、原点已确认，排风已开启”后点“批准并开始”；不想执行就点“拒绝”。请求 120 秒内没有处理会自动过期。
- 请求之后如果重新预览、换了设备或改了发送方式，批准时会提示“摘要不一致”，不会执行，需要重新发起。
- 急停、取消、降低速度或功率等停止类动作任何时候都能直接执行。
- 只有桌面端能批准；用浏览器打开 MOSS 页面不能批准，严格模式下浏览器页面自己的加工请求也会被拒绝。
- 关闭：删除这一行，完全退出后重新打开。

### MOSS 内置语音服务

不装任何外部服务端，让小智设备直接连到 MOSS：MOSS 自己完成识别、调用大模型、朗读回答，并能按你的语音查询或准备加工任务。开始加工前，MOSS 会先复述材料、厚度、内容与功率速度次数，等你明确说“确认”或“开始”。**是否还要在电脑上批准取决于严格模式**：`.env` 中 `MOSS_FUSION_STRICT=true` 时必须在电脑上批准；未开启时口头确认后就会直接加工（与官方小智链路相同）——请确认材料放好、有人在旁、能随时按硬件急停。

1. **准备模型**：内置服务使用 OpenAI 兼容接口的语音识别（`/audio/transcriptions`）、大模型（`/chat/completions`，需支持工具调用）与语音合成（`/audio/speech`，需能返回 WAV）。在语音中心“模型”标签的“大模型”“语音识别”“语音合成”三组中分别填写地址、密钥、模型（合成另有音色、语速），先点“测试连接”，通过后再点该组的“保存…设置”。密钥只保存在本机数据库，不写入 `settings.json` 与日志，页面也不再显示；输入框留空表示沿用已保存的密钥，“删除此项”会同时删除密钥。三项都配置后内置服务为“对话”模式，否则为“回声测试”模式（把你的声音播回，用来确认连接与音质）。
2. **切换链路**：在语音中心顶部的“语音链路”选择“MOSS 内置服务”。确认框会列出将发生的变化；之后内置服务随 MOSS 自动启动（也可以在“服务与设备”标签手动启动 / 停止）。第一次启动时 Windows 防火墙会询问是否允许 MOSS 联网，选择允许（专用网络）。
3. **改设备 OTA 地址**：“服务与设备”标签显示“设备 OTA 地址”（形如 `http://<电脑局域网IP>:8003/xiaozhi/ota/`）。在设备的配网页面“高级选项”中把“自定义 OTA 地址”改成它并重启设备；设备和电脑要在同一个局域网。清空该地址即恢复官方服务器。
4. **允许设备**：设备第一次连上时会提示“等待允许”，同时出现在设备列表中。核对型号后点“允许”，再重启设备一次。
5. **对话**：唤醒设备后说话，停顿约 0.2 秒即开始回答（按住说话模式松开即开始）；播放中再次唤醒或按键会立即打断。说“退出”“再见”等结束对话；120 秒没有对话会说再见并断开。顶栏小智胶囊显示“内置 · 等待设备 / 已连接”。
6. **加工**：说“在 3 毫米椴木板上刻你好”之类的话时，MOSS 先生成预览；要开始加工，它会复述参数并问“确认开始吗”。你说“确认”后：严格模式开启时设备会说“已发到电脑，请在电脑上的 MOSS 里确认后开始”，电脑上弹出审批卡（来源显示“小智语音（MOSS 内置）”及设备），勾选现场确认后才会发送；严格模式未开启时直接发送。急停、取消等停止类指令立即执行。命令执行、打开应用等电脑控制工具不对内置语音开放。
7. **本地模型（可选）**：“模型”标签的“本地模型”分判停、语音识别、语音合成三类，每类有几个模型可选，每个模型下面写着优缺点（例如 X-ASR 流式识别边说边识别、回答最快；Matcha 合成最快但只有一个音色；Kokoro 音质自然但较慢）。点“下载”保存到运行目录的 `models` 文件夹，下载后自动校验 SHA-256；GitHub 慢时可在“模型下载地址”填镜像。每类选中一个模型、打开该类的开关并点“保存本地模型设置”后，识别、合成、判停就在本机完成，不需要密钥、断网也可用（大模型仍需云端，或本机 Ollama 等 OpenAI 兼容服务）。本地模型由与 MOSS 同目录的 `moss-voice-local.exe` 运行，找不到它时页面会提示。快捷查询、热词、插话在单独的“语音体验”组，单独保存。
8. **豆包流式（可选，更快）**：“模型”标签的语音识别、语音合成两组可把“接口类型”改为“豆包流式”。识别会在你开口时就开始、边说边传，说完很快出文字；合成会边生成边播放，不必等整句合成完。在火山引擎控制台开通豆包流式语音识别 / 语音合成，把 API Key 填进“API Key”（旧版控制台填“APP ID:Access Token”，中间是英文冒号）；地址与资源 ID 已自动填默认值，与你开通的服务不同时再改；合成还需填音色 ID（见控制台音色列表）。同样先测试、后保存。
9. 端口 8000 / 8003 被占用（例如外部 xiaozhi-server 正在运行）时启动会失败，“服务与设备”标签会显示原因；先停掉它或在“连接”标签的“内置服务端口”组换端口。环境很吵时可能判断不出说完，可改用按住说话。

### 语音中心（桌面端）

左侧导航第四项“语音中心”，只在 MOSS 桌面端出现（浏览器、手机、独立 `moss-host` 没有）。

页面顶部选语音链路，并显示一行状态（服务、设备、严格模式）；下面分“服务与设备”“模型”“连接”“功能扩展”“记录与诊断”五个标签。每个标签只把当前链路用得到的设置放在前面，其他链路的设置折叠在最后，需要时点“其他链路的…设置”展开。每项设置是一个可折叠的组，收起时显示一行摘要；**每组单独保存**，按钮写着保存的是什么（例如“保存官方接入点”“保存大模型设置”），没改动时不能点。改了没保存的组会显示“未保存”，所在标签上也有一个小圆点；切换标签或收起组不会丢失已填写的内容。保存结果（保存了什么、几点、什么时候生效）显示在按钮旁边。

1. **语音链路**：三选一（“MOSS 内置服务”见上一节）。
   - **官方小智**（默认）：设备连官方服务器，MOSS 作为工具接入官方接入点。在“连接”标签的“官方接入点”组填写小智控制台生成的 `wss://…` 地址，点“保存官方接入点”，会立即重新连接。
   - **自建服务端**：设备连你自己运行的 xiaozhi-server。切换前先在“连接”标签填好“自建接入点”组（接入点控制台打印的“单模块部署 MCP 接入点”`ws://…/mcp_endpoint/mcp/?token=…`）。切换时会弹出确认框列出将修改的设置：严格模式开启（自建模式下不能关闭）、MOSS 的接入点改为自建地址、原来的官方地址自动备份，切回官方时恢复。
   - MOSS **不会修改设备**：切换后需要你自己把设备的 OTA 地址改到对应服务器（自建为 `http://<服务端地址>:8003/xiaozhi/ota/`）。页面会根据服务端是否看到设备，提示设备连接是否与所选链路一致；没有填写“接入点健康检查地址”（接入点控制台打印的“智控台 MCP 参数”`http://…/mcp_endpoint/health?key=…`）时显示“未知”。
2. **服务端**：在“连接”标签的“自建服务端程序”组填写 xiaozhi-server 目录（`main/xiaozhi-server`）、Python 3.10 路径并保存后，可在“服务与设备”标签启动、停止、重启。端口已被其他程序占用时显示“外部运行”，MOSS 不会再启动一个，也不能停止它。服务端意外退出时显示退出码，不会自动重启。日志在“记录与诊断”标签（运行目录 `logs/xiaozhi-server.log`，5 MB × 3 份），密钥类字段已替换为 `***`。
3. **模型配置**：在“模型”标签，大模型、语音识别、语音合成三组分别填写地址、密钥、模型（语音合成还有音色、语速）。先点“测试连接”，成功后才能点“保存…到服务端配置”；测试后改了任何内容都要重新测试。保存写入服务端的 `data/.config.yaml`（原文件备份为 `.config.yaml.bak`，其他内容与注释保留），只改这一组；密钥留空则保留文件里原来的密钥。写入后需要重启服务端生效，按钮旁会出现“立即重启服务端”。服务端若是全模块部署（由智控台管理配置），这里只能测试、不会写文件。
4. **密钥**：模型密钥只写进服务端自己的配置文件，MOSS 的数据库、`settings.json` 与日志都不保存；页面也不回显已保存的密钥。
5. **审批记录**：“记录与诊断”标签列出最近的审批请求及结果（待批准、已完成、已拒绝、已过期、摘要不一致、急停等）。

### 接入点与工具（桌面端）

语音中心“连接”标签的“接入点状态”与“工具开关与调用统计”两组（添加、删除、勾选都立即生效，不需要另外保存）：

- **多个接入点**：除主接入点外，可再添加最多 4 个小智控制台生成的接入点（例如同一账号的其他智能体），MOSS 同时连接它们，提供同一套工具。每个接入点显示是否在线、自动重连了几次、上次断开的原因，以及 token 里的智能体 ID 与有效期（过期会标红，需要到小智控制台重新生成）。自建模式下附加接入点暂停连接。
- **工具开关**：不想让小智使用的工具可以取消勾选。关闭后小智看不到这个工具，就算调用也会被拒绝；内置语音同样生效。停止与急停工具不能关闭。改动后 MOSS 会重新连接接入点，几秒内生效。
- **调用统计**：每个工具本次运行以来被调用、失败、被拒绝的次数，以及最近一次的时间和来源。

“功能扩展”标签放本地音乐、视觉理解、第三方 MCP 工具，以及打开“安全设置窗口”（私人记忆、长期记忆、信息插件、声纹、家居）的按钮；这些功能只在“MOSS 内置服务”链路下生效。尚未通过安全验收的功能（如 Claude Code / Codex 调用）放在默认折叠的“实验功能”里，执行保持锁定。

### 长期记忆（安全设置窗口）

在“安全设置窗口”的“长期记忆、资料与恢复摘要”卡片里管理。所有内容只存在本机，都是参考数据，不能授权任何设备操作。

- **两个开关，默认都关**：“语音对话时检索”会在你提问时查出最多 3 条相关记忆和少量资料摘录，不调用大模型；“会话结束后自动提取”会把过滤后的对话文字发给你配置的大模型，提取出的只是候选，要你在这里确认，开启前会再问一次。闲聊、“停止”和快捷查询不会去查记忆。
- **当前项目**：设一个当前项目后，资料目录、任务类记忆和恢复摘要都挂在它下面，语音也按它来查。换项目后，旧项目还没完成的提取会作废。
- **记忆条目**：按设备或项目查看、查找、新增、编辑、确认、作废（不能恢复）、删除、清空、导出备份；有旧的“设备记忆”摘要时可以导入为候选。每次自动提取都有记录，可以整批撤销，你改过或确认过的会保留。
- **资料目录**：点“添加资料文件夹…”选择本机文件夹，只读里面的 txt / md / csv 文本，摘要在本机生成、不上传；会跳过链接、隐藏文件和名字像密码 / 密钥的文件。文件改了要点“重建索引”，移除目录不会删除磁盘上的文件。
- **设备故障经验**：按设备记录现象、排查步骤和结论，绑定该设备登记的机型和固件版本，换固件后不会套用；勾选“我确认已解决”才算已验证。
- **项目恢复摘要**：分决策、待办、证据、未验证四栏，每行一条，可以写 `[job:编号]`、`[approval:编号]` 引用记录。查看时会重新核对这些记录的实际状态；结果未知、已撤销或已停止的任务不会被自动重试。

## 9. 常见问题

- **串口列表为空**：列表只显示系统识别到的串口，插好设备后点右侧刷新；也可以选择"手动输入串口"。
- **握手报 `$32=1 固件激光模式门禁未通过`**：固件未启用激光模式，按 [FluidNC 固件侧配置](../laser/fluidnc-setup.md) 在 `config.yaml` 写 `Laser:` 段。
- **提示"机器正在执行 SD 脱机作业"**：固件会丢弃其他通道的顺序指令，先急停再操作。
- **报 `error:162 Read-only setting`**：FluidNC 的 `$30`、`$32`、`$100` 等是只读代理，改 `config.yaml` 后重启，上位机不会替你改。
- **端口被占用**：看控制台打印的实际端口，或在偏好设置里换端口。
- **页面提示需要配对码**：说明你不是从宿主机本机访问，按第 7 节获取配对码。
- **接口返回 403 `origin_not_allowed`**：请求来自一个不在允许范围内的网页（例如你自己另起端口托管的前端）。MOSS 不允许任意网页跨站调用；确需使用时把该页面的来源（`http://<主机>:<端口>`，不带路径）加到 `MOSS_ALLOWED_ORIGINS` 后重启。
- **启动报 `MOSS_ALLOWED_ORIGINS 不允许包含 *`**：删除 `*`，改写具体来源。
- **本机访问返回 403 `host_not_allowed`**：在本机请用 `http://127.0.0.1:<端口>` 或 `http://localhost:<端口>` 打开，不要用自定义域名或 hosts 文件里的别名（这是防 DNS 重绑定攻击的保护）。确需用别名时，把 `http://<别名>:<端口>` 加到 `MOSS_ALLOWED_ORIGINS`。
## Jev 加工反馈

在设置中保存 **OpenRouter API Key** 并启用 Jev，模型固定为 `typesafe/jev-1.13`，无需填写服务地址。旧 TypeSafe 服务的 Key 需要替换；API Key 保存方式保持原样。

生成任务后，可在主页或画板的“加工反馈”区域描述效果，查看原参数、建议及判断来源。点击“采用并生成新预览”只产生新任务，不启动设备；检查新预览后仍需单独确认发送。判断不明确时不调整参数。历史随关联任务保存，服务未启用或失败时会明确标出本地规则。

## 导出文件保存在哪里

创作画板的 PNG / 场景 JSON / G-code 下载、材料实验室的“导出库”都经同一处保存：

- **桌面版（Windows）**：默认保存到“下载”文件夹，导出后弹窗显示完整路径，可点“打开所在文件夹”。在 **偏好设置 → 导出** 里可以：
  - “选择文件夹…”改为任意文件夹（只能通过系统选择框选，不能手输路径）；
  - “恢复默认”回到下载文件夹；“打开文件夹”直接打开当前导出目录；
  - 勾选“每次导出时询问保存位置”，之后每次导出都弹“另存为”框，取消即放弃本次导出。
- 选的文件夹之后不可用（U 盘拔了、网络盘断了、没有写权限）时，导出**不会自动换地方保存**，会提示你“重新选择”或“本次保存到下载文件夹”。
- **Android 与浏览器访问**：没有“导出”设置；Android 保存在系统下载目录（不可用时退回应用私有目录，提示里会显示路径），浏览器按浏览器自己的下载设置保存。
- 导出目录与运行数据目录（`%APPDATA%\moss`）无关；卸载 MOSS 不会删除导出目录里的文件。

## 安装与卸载

### 生成安装包（开发者）

先构建前端，再打包（桌面打包不会自动构建前端，顺序不能反）：

```powershell
cd frontend
npm run build
cd ..\apps\desktop\src-tauri
cargo tauri build
```

产物：`target\release\bundle\nsis\MOSS_<版本>_x64-setup.exe`（同时仍会生成 `target\release\moss-desktop.exe`）。第一次打包时 Tauri 会联网下载 NSIS 打包工具。安装包目前**未签名**，在别的电脑上运行时 Windows 可能提示“未知发布者”，选“仍要运行”即可（正式分发前需代码签名）。

### 安装

1. 运行 `MOSS_<版本>_x64-setup.exe`。
2. 选择“只为我安装”（不需要管理员，默认装到 `%LOCALAPPDATA%\MOSS`）或“为所有用户安装”（需要管理员，默认 `C:\Program Files\MOSS`）。
3. 在下一页可以**改成任意安装目录**（支持中文和空格）。
4. 完成后从开始菜单“MOSS”文件夹或桌面快捷方式启动。没有 WebView2 的电脑会自动联网安装。

如果 MOSS 正在运行，安装程序只会提示你先退出（托盘图标右键“退出程序”），不会强行结束它——强行结束会跳过激光任务的安全停止顺序。

### 卸载

在 Windows“设置 → 应用”、开始菜单或安装目录下的 `uninstall.exe` 卸载。卸载页的“删除应用程序数据”**默认不勾选**：

- 不勾选：只删除程序，`%APPDATA%\moss` 里的材料库、任务记录、设置都保留，重新安装后继续使用；
- 勾选：同时删除 `%APPDATA%\moss`。

卸载不会删除你自备的小智服务端目录或导出的文件。新版本直接覆盖安装即可升级，数据不受影响。

详细规则见 [安装包与卸载规范](../developer/packaging-install.md)。
