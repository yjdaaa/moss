# FluidNC 与 MOSS 烧录后测试清单

适用工程：

- 上位机：`<path>/moss`
- 下位机：`<path>/FluidNC-main`
- 当前 FluidNC 配置：`FluidNC\data\config.yaml`
- 当前测试对象：ESP32 / FluidNC / 激光机 / SD 卡脱机加工

本文档用于固件和 WebUI 烧录后的验收。测试应按顺序执行，不要跳过前置安全检查。

## 一、测试边界

### 1. 两个项目的职责

- `moss-rust` 是上位机，负责生成 G-code、连接 FluidNC、上传文件、哈希校验和启动任务。
- `FluidNC-main` 是 ESP32 下位机固件和 WebUI。
- 两个项目通过串口、Telnet、HTTP 和 FluidNC 命令配合，不是通过目录自动同步。

### 2. SD 脱机流程

MOSS 网络模式下的 SD 脱机流程为：

```text
HTTP POST /upload
  -> $File/ShowHash=/sd/<文件名>
  -> $SD/Run=/sd/<文件名>
  -> 读取 SD: 进度
  -> SD 文件结束
  -> 等待 FluidNC 回到 Idle
```

当前 MOSS 自动上传 SD 文件只支持网络连接。串口模式不能自动把文件传到 SD 卡。

### 3. 高风险测试说明

以下动作涉及真实硬件副作用，必须由操作者在现场确认后执行：

- 运行任何 G-code 文件；
- 电机点动、回零、边框预览；
- 激光出光；
- 气泵动作；
- 急停、限位和门保护测试；
- SD 脱机加工。

前面的软件、通信和只读检查没有全部通过时，不得进入运动和出光测试。
